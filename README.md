# GitAccounter

Git 인증 정보를 간편하게 교체하고 관리해주는 프로그램입니다.

GitHub CLI(`gh`)에 계정을 여러 개 등록해 두고 필요할 때 바꿔 쓸 수 있지만, 바꿀 때마다 계정 이름을 정확히 쳐야 합니다. GitAccounter는 등록한 계정에 번호를 붙여 보여 줍니다. 번호만 누르면 계정을 바꿉니다.

## 화면

```
============================================================
   GitHub 계정 전환기
============================================================

   [1] first-account   (github.com)   <-- 현재 사용 중
   [2] second-account  (github.com)

------------------------------------------------------------
   번호           해당 계정으로 전환      예) 1
   번호 status    해당 계정의 인증 정보   예) 1 status
   번호 logout    해당 계정 인증 해제     예) 1 logout
   login          새 계정 로그인
   link [경로]    바로 가기 생성          예) link D:\도구
   r              목록 새로 고침
   q              종료
------------------------------------------------------------

입력:
```

## 필요한 것

[GitHub CLI](https://cli.github.com)가 필요합니다. `gh`를 찾지 못하면 프로그램이 설치 주소를 알려 주고 끝납니다.

## 사용 방법

`GitAccounter.bat`을 실행하면 등록한 계정이 목록으로 나옵니다. 계정을 이름순으로 늘어놓기 때문에, 쓰는 계정을 바꾸어도 번호는 그대로입니다.

| 입력 | 동작 |
| --- | --- |
| `1` | 1번 계정으로 바꿉니다. |
| `1 status` | 1번 계정의 호스트, 지금 쓰는 계정인지 여부, 프로토콜, 토큰 권한 범위를 보여 줍니다. |
| `1 logout` | 정말 해제할지 한 번 물어본 뒤 1번 계정의 인증을 해제합니다. |
| `login` | 브라우저로 새 계정을 추가합니다. 이미 등록한 계정은 건드리지 않습니다. |
| `link` | 배치 파일이 있는 폴더에 바로 가기를 만듭니다. |
| `link D:\도구` | 지정한 폴더에 바로 가기를 만듭니다. |
| `r` | 목록을 새로 고칩니다. |
| `q` | 끝냅니다. |

### link 명령

경로를 빼고 `link`만 치면 배치 파일이 있는 폴더에 `GitAccounter.lnk`를 만듭니다. 경로를 붙이면 다음 규칙을 따릅니다.

- 폴더를 주면 그 안에 `GitAccounter.lnk`를 만듭니다.
- `.lnk`로 끝나는 경로를 주면 그 이름 그대로 만듭니다. 이때 상위 폴더가 있어야 합니다.
- 공백이 들어간 경로는 따옴표로 감싸도 되고 그냥 쳐도 됩니다.
- `%USERPROFILE%` 같은 환경 변수를 씁니다.
- 상대 경로는 배치 파일이 있는 폴더를 기준으로 삼습니다.

폴더가 없거나, 폴더 대신 파일을 가리키거나, 경로에 `< > | * ?` 가 들어 있으면 아무것도 만들지 않고 무엇이 잘못됐는지 알려 줍니다. 같은 이름의 바로 가기가 이미 있으면 덮어쓰지 않고 그대로 둡니다.

바로 가기를 만들고 나면 전체 경로를 찍어 줍니다. Windows Terminal에서 실행했다면 그 경로에 하이퍼링크를 겁니다. `Ctrl` 키를 누른 채 누르면 폴더가 열립니다.

## 아이콘

배치 파일에는 아이콘을 담을 자리가 없습니다. 그래서 파일마다 아이콘을 다르게 주려면 바로 가기를 거쳐야 합니다. `link` 명령으로 만든 바로 가기는 옆에 있는 `GitAccounter.ico`를 아이콘으로 씁니다.

아이콘은 16×16 격자에 도트를 하나씩 찍어 그렸습니다. 16부터 256 픽셀까지 다섯 가지 크기를 한 파일에 담았고, 키울 때 보간을 끄고 정수 배율만 써서 큰 크기에서도 도트가 각지게 남습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `GitAccounter.bat` | 프로그램 본체 |
| `GitAccounter.ico` | 바로 가기에 붙이는 아이콘 |

바로 가기 파일은 만든 컴퓨터의 절대 경로를 품고 있어서 저장소에서 추적하지 않습니다. 내려받으신 뒤 `link` 명령으로 직접 만들어 쓰십시오.

## 주의 사항

`GitAccounter.bat`은 CP949로 인코딩하고 CRLF 줄바꿈을 씁니다. 한글이 들어간 배치 파일에서 이 두 가지를 지키지 않으면 명령 프롬프트가 파일을 잘못 읽어 엉뚱한 줄을 명령으로 실행합니다. 저장소에서는 `.gitattributes`로 줄바꿈 변환을 막아 두었으니, 편집하실 때에도 인코딩과 줄바꿈을 그대로 두십시오.

바로 가기는 배치 파일과 아이콘의 위치를 절대 경로로 가리킵니다. 폴더를 옮기셨다면 `link` 명령으로 다시 만드십시오.
