# GitAccounter

Git 인증 정보를 간편하게 교체하고 관리해주는 프로그램입니다.

GitHub CLI(`gh`)는 하나의 호스트에 여러 계정을 등록해 두고 필요할 때 전환하는 기능을 제공하지만, 매번 계정 이름을 정확히 입력해야 합니다. GitAccounter는 등록된 계정을 번호가 붙은 목록으로 보여 주고, 번호만 입력하면 전환되도록 만든 배치 파일입니다.

## 화면

```
============================================================
   GitHub 계정 전환기
============================================================

   [1] first-account   (github.com)   <-- 현재 사용 중
   [2] second-account  (github.com)

------------------------------------------------------------
   번호           해당 계정으로 전환      예) 1
   번호 status    해당 계정의 인증 정보   예) 1 status
   번호 logout    해당 계정 인증 해제     예) 1 logout
   login          새 계정 로그인
   link [경로]    바로 가기 생성          예) link D:\도구
   r              목록 새로 고침
   q              종료
------------------------------------------------------------

입력:
```

## 필요한 것

[GitHub CLI](https://cli.github.com)가 설치되어 있어야 합니다. 설치되어 있지 않으면 프로그램이 안내 문구를 출력하고 종료합니다.

## 사용 방법

`GitAccounter.bat`을 실행하면 등록된 계정 목록이 나타납니다. 목록은 계정 이름순으로 정렬되므로, 활성 계정이 바뀌어도 번호는 그대로 유지됩니다.

| 입력 | 동작 |
| --- | --- |
| `1` | 1번 계정으로 전환합니다. |
| `1 status` | 1번 계정의 호스트, 활성 여부, 프로토콜, 토큰 권한 범위를 보여 줍니다. |
| `1 logout` | 확인 질문을 거친 뒤 1번 계정의 인증을 해제합니다. |
| `login` | 브라우저를 통해 새 계정을 추가합니다. 기존 계정의 인증은 유지됩니다. |
| `link` | 배치 파일이 있는 폴더에 바로 가기를 만듭니다. |
| `link D:\도구` | 지정한 폴더에 바로 가기를 만듭니다. |
| `r` | 목록을 새로 고칩니다. |
| `q` | 종료합니다. |

### link 명령

경로를 생략하면 배치 파일이 있는 폴더에 `GitAccounter.lnk`를 만듭니다. 경로를 지정하는 경우에는 다음 규칙을 따릅니다.

- 폴더를 지정하면 그 안에 `GitAccounter.lnk`를 만듭니다.
- `.lnk`로 끝나는 경로를 지정하면 그 이름 그대로 만들며, 상위 폴더가 존재해야 합니다.
- 공백이 포함된 경로는 따옴표로 감싸도 되고 그냥 입력해도 됩니다.
- `%USERPROFILE%` 같은 환경 변수를 사용할 수 있습니다.
- 상대 경로는 배치 파일이 있는 폴더를 기준으로 해석합니다.

폴더가 없거나, 폴더가 아닌 파일을 가리키거나, 경로에 `< > | * ?` 가 들어 있으면 만들지 않고 오류를 안내합니다. 같은 이름의 바로 가기가 이미 있으면 덮어쓰지 않고 그대로 둡니다.

생성에 성공하면 만들어진 전체 경로를 출력합니다. Windows Terminal에서 실행한 경우에는 경로에 하이퍼링크가 걸려서, `Ctrl` 키를 누른 채 누르면 해당 폴더가 열립니다.

## 아이콘

배치 파일에는 아이콘을 담을 수 있는 리소스 영역이 없기 때문에, 개별 파일마다 아이콘을 지정하려면 바로 가기를 사용해야 합니다. `link` 명령으로 만든 바로 가기에는 함께 들어 있는 `GitAccounter.ico`가 적용됩니다.

아이콘은 16×16 격자에 직접 도트를 찍어 만들었으며, 16부터 256 픽셀까지 다섯 가지 크기를 하나의 파일에 담았습니다. 확대할 때 보간을 사용하지 않아 큰 크기에서도 도트의 각진 느낌이 유지됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `GitAccounter.bat` | 프로그램 본체입니다. |
| `GitAccounter.ico` | 바로 가기에 사용하는 아이콘입니다. |

바로 가기 파일은 만들어진 컴퓨터의 절대 경로를 담고 있어서 저장소에서는 추적하지 않습니다. 내려받으신 뒤 `link` 명령으로 직접 만들어 사용하십시오.

## 주의 사항

`GitAccounter.bat`은 CP949 인코딩에 CRLF 줄바꿈으로 저장되어 있습니다. 한글이 포함된 배치 파일은 이 조건이 지켜지지 않으면 명령 프롬프트가 파일을 잘못 읽어 동작하지 않습니다. 저장소에는 `.gitattributes`로 줄바꿈 변환을 막아 두었으니, 편집하실 때에도 인코딩과 줄바꿈을 유지해 주십시오.

바로 가기는 배치 파일과 아이콘의 위치를 절대 경로로 가리킵니다. 폴더를 옮기신 경우에는 `link` 명령으로 다시 만들어 주십시오.
