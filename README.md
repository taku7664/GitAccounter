# GitAccounter

Git 인증 정보를 간편하게 교체하고 관리해주는 프로그램입니다.

회사 계정과 개인 계정을 오갈 때마다 `gh auth switch --hostname github.com --user ...`를 치면서 계정 이름을 정확히 기억해 내야 합니다. 이름을 잘못 치면 엉뚱한 계정으로 푸시하거나 권한이 없다는 오류를 봅니다. GitAccounter는 등록한 계정에 번호를 붙여 보여 줍니다. 번호만 입력하면 계정을 바꿉니다.

## 내려받기

[**GitAccounter.zip 내려받기**](https://github.com/taku7664/GitAccounter/releases/latest/download/GitAccounter.zip) — 늘 최신 판을 가리킵니다.

[릴리즈 목록](https://github.com/taku7664/GitAccounter/releases)에서 지난 판도 받을 수 있습니다.

## 필요한 것

Windows와 [GitHub CLI](https://cli.github.com)가 필요합니다. `gh`를 찾지 못하면 프로그램이 설치 주소를 알려 주고 끝납니다.

## 설치

1. `GitAccounter.zip`을 받아 원하는 폴더에 풉니다. `GitAccounter.bat`과 `GitAccounter.ico`를 같은 폴더에 두십시오.
2. `GitAccounter.bat`을 실행합니다.
3. `link`를 입력해 바로 가기를 만듭니다. 바탕 화면에 두시려면 `link %USERPROFILE%\Desktop`이라고 입력하십시오.

바로 가기로 실행하면 아이콘이 붙습니다. 배치 파일에는 아이콘을 담을 자리가 없어서, 아이콘을 보려면 바로 가기를 거쳐야 합니다.

## 화면

```
============================================================
   GitHub 계정 전환기
============================================================

   [1] first-account   (github.com)   <-- 현재 사용 중
   [2] second-account  (github.com)

------------------------------------------------------------
   번호           해당 계정으로 전환      예) 1
   번호 status    해당 계정의 인증 정보   예) 1 status
   번호 logout    해당 계정 인증 해제     예) 1 logout
   login          새 계정 로그인
   link [경로]    바로 가기 생성          예) link D:\도구
   r              목록 새로 고침
   q              종료
------------------------------------------------------------

입력:
```

## 사용 방법

`GitAccounter.bat`을 실행하면 등록한 계정이 목록으로 나옵니다. 계정을 이름순으로 늘어놓기 때문에, 쓰는 계정을 바꾸어도 번호는 그대로입니다.

| 입력 | 동작 |
| --- | --- |
| `1` | 1번 계정으로 바꿉니다. |
| `1 status` | 1번 계정의 호스트, 지금 쓰는 계정인지 여부, 프로토콜, 토큰 권한 범위를 보여 줍니다. |
| `1 logout` | 정말 해제할지 한 번 물어본 뒤 1번 계정의 인증을 해제합니다. |
| `login` | 브라우저로 새 계정을 추가합니다. 이미 등록한 계정은 건드리지 않습니다. |
| `link` | 배치 파일이 있는 폴더에 바로 가기를 만듭니다. |
| `link D:\도구` | 지정한 폴더에 바로 가기를 만듭니다. |
| `r` | 목록을 새로 고칩니다. |
| `q` | 끝냅니다. |

### link 명령

경로를 빼고 `link`만 치면 배치 파일이 있는 폴더에 `GitAccounter.lnk`를 만듭니다. 경로를 붙이면 다음 규칙을 따릅니다.

- 폴더를 주면 그 안에 `GitAccounter.lnk`를 만듭니다.
- `.lnk`로 끝나는 경로를 주면 그 이름 그대로 만듭니다. 이때 상위 폴더가 있어야 합니다.
- 공백이 들어간 경로는 따옴표로 감싸도 되고 그냥 쳐도 됩니다.
- `%USERPROFILE%` 같은 환경 변수를 씁니다.
- 상대 경로는 배치 파일이 있는 폴더를 기준으로 삼습니다.

폴더가 없거나, 폴더 대신 파일을 가리키거나, 경로에 `< > | * ?` 가 들어 있으면 아무것도 만들지 않고 무엇이 잘못됐는지 알려 줍니다. 같은 이름의 바로 가기가 이미 있으면 덮어쓰지 않고 그대로 둡니다.

바로 가기를 만들고 나면 전체 경로를 찍어 줍니다. Windows Terminal에서 실행했다면 그 경로에 하이퍼링크를 겁니다. `Ctrl` 키를 누른 채 누르면 폴더가 열립니다.

## 문제가 생기면

**아이콘이 안 보입니다.** `GitAccounter.ico`가 배치 파일과 같은 폴더에 있는지 확인하고, `link`로 바로 가기를 다시 만드십시오.

**바로 가기를 눌러도 아무 일이 없습니다.** 폴더를 옮기면 바로 가기가 예전 경로를 가리킵니다. `link`로 다시 만드십시오.

**화면의 한글이 깨집니다.** `GitAccounter.bat`을 편집하셨다면 CP949 인코딩과 CRLF 줄바꿈이 그대로인지 확인하십시오. 둘 중 하나라도 바뀌면 명령 프롬프트가 파일을 잘못 읽어 엉뚱한 줄을 명령으로 실행합니다. 릴리즈에서 다시 받으면 원래대로 돌아옵니다.
